# Передай трубку

Собранное приложение. Открывается по адресу
**https://sich-io.github.io/trubka/** — ставится на домашний экран
и работает офлайн.

Шуточная игра для компании: телефон лежит на столе, следит за очередью
трубки и комментирует происходящее. Ничего не записывает и никуда
не отправляет — всё остаётся на телефоне.

Файлы здесь собираются автоматически и руками не правятся: правки
вносятся в исходный репозиторий, оттуда приезжает новая сборка.
